# Diretriz de Git Push

- **Sempre mostrar o botão/comando de Push**: Sempre que houver código commitado pronto para envio remoto (ou sempre que uma operação de push for necessária), exiba claramente o comando e o botão interativo de `git push origin main` na interface para que o usuário aprove e clique no botão de push.
- Evite executar pushes de forma silenciosa ou oculta sem que o usuário veja o bloco de comando interativo.
